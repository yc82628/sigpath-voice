Things to try

  • SP-1042: shipped, money still in escrow
  • SP-1043: paid, waiting for the shop to ship
  • SP-1044: delivered, escrow released
  • SP-1045: refunded
  • SP-1099: the order service fails, to see how the agent handles it
  • Say an order number the way people do: "S P one oh four two"
  • Report a problem: "my order SP-1044 arrived broken"
  • Ask for a person (works if a transfer number is set up)
